# START_HERE.md — repo pack manifest

Unzip this at the repo root. The folder layout below is load-bearing: CLAUDE.md
expects `seed_docs/` where it is, and the FIXED payroll file is deliberately kept
OUT of `seed_docs/` so the seed extraction never ingests it.

## Kickoff prompt for Claude Code (paste as the first task)

> Read CLAUDE.md and ARCHITECTURE.md in full before writing any code. They are
> the complete specification; ARCHITECTURE.md contains the system diagram, ERD,
> and re-scan sequence. Then execute Phase 0 from CLAUDE.md and stop for review.

Run each subsequent phase as its own task (`/clear` between phases). Docker work
only via DOCKER.md, per its own timing rules.
